# Cogwright — QA-Checklisten

## Global

- [ ] Asset folgt der warm-düsteren Werkstatt-Art-Direction
- [ ] Messing/Kupfer/Eisen wirken gealtert, nicht steril
- [ ] keine Neonfarben als Hauptakzent
- [ ] kein Text, kein Wasserzeichen, kein eingebauter Rahmen außer bei UI-Assets
- [ ] Datei korrekt benannt
- [ ] Auflösung und Alpha stimmen
- [ ] Asset funktioniert auf dunklem Hintergrund

## Item-Icons

- [ ] bei 128x128 klar lesbar
- [ ] bei 64x64 noch erkennbar
- [ ] bei 32x32 Hauptform noch erkennbar
- [ ] zentriert, keine abgeschnittenen Teile
- [ ] kein zu starkes Partikelrauschen
- [ ] Tag-Farbe nur als Akzent, nicht als Vollflächenfarbe

## Charaktere

- [ ] Licht konsistent von rechts oben
- [ ] Gesicht/Brustbereich lesbar
- [ ] Accessoire/Motiv eindeutig
- [ ] transparente Kanten sauber
- [ ] Proportionen nicht cartoonhaft überzogen

## Bosse

- [ ] Silhouette sofort unterscheidbar
- [ ] Boss-Motiv klar erkennbar
- [ ] nicht zu detailrauschig
- [ ] dunkle Stimmung, aber nicht unlesbar

## Backgrounds

- [ ] Layer horizontal tilebar oder zumindest nahtarm
- [ ] Parallax-Tiefe klar: Sky/Far/Mid/Foreground
- [ ] keine Figuren
- [ ] keine harten Kanten an den Seiten

## UI

- [ ] 9-slice-Zonen korrekt: 24px Randzone
- [ ] Mitte sauber streckbar
- [ ] Hover/Pressed unterscheiden sich sichtbar, aber subtil
- [ ] Text später gut lesbar auf dem Hintergrund

## Partikel

- [ ] Alpha-Kanten weich
- [ ] kleine Auflösung bleibt lesbar
- [ ] keine harten weißen Ränder
- [ ] nicht zu hell, damit Effekte nicht flackern/überstrahlen
